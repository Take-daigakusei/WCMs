# WCMs

サークル用アプリ（開発中）。

## 開き方
- パソコン：`index.html` をダブルクリック（ブラウザで開きます）
- 公開後：GitHub Pages の URL をスマホで開き、「ホーム画面に追加」でアプリのように使えます

## 構成
| ファイル | 役割 |
|---|---|
| `index.html` | 画面・見た目・処理をすべてこの1ファイルに書く |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・色・アイコン |
| `icon.svg` / `icon-*.png` | アイコン（仮のもの。差し替えてOK） |
| `lib/` | 外部ライブラリを使う場合のローカル保存先（オフライン用） |

## 公開のしかた（無料）
1. GitHub に `WCMs` リポジトリを作って push
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
3. `https://take-daigakusei.github.io/WCMs/` で開けるようになります

## 使い方（飲み会の集合ボード）
サークル後、班に分かれてお店へ → 高田馬場のロータリー（ロタ）に集合 → 二次会、という流れ用。**位置情報は使いません。**
**ボードを作る操作はありません。** その日に最初に開いた人が開いたときに、今日のボードが自動で作られます（朝4時に日付が変わります）。
1. アプリを開く → 今日のボードが開く。出席者が名簿として入る（出欠アプリの名簿に残っている〇・遅刻と、今日の練習としてチーム履歴に記録済みの人。練習後に〇がリセットされたあとでも入る）
2. 初回だけ、自分の名前を登録する（名簿から選ぶか、入力する）。端末が名前を覚えるので、次からは開くだけで自分として入れる（練習に出ていない日でも、名前を選び直さずに入れる）
   - アフターから参加する人（練習に出ていない人）は、名前の登録画面の「アフターから参加する人：名前を入力」から入る。お店を選ばなくても「ロタへ向かう」「ロタに着いた」を押せる（同じボタンをもう一度押すと取り消し）
3. 練習のあと、幹事が行くお店をラジオボタンで選ぶ（みんなに公開される）
   - お店の載せ方は3つ（二次会の候補も同じ）：①検索欄をタップして、候補（前に使ったお店・いつものお店）から選ぶ ②名前を入れて「追加して選ぶ」を押す ③Googleマップでお店のページを開き、アドレス欄の長いURLを貼る（`maps.app.goo.gl` などの短縮URLは読み取れない）
   - 一度載せたお店は、開いていた端末が覚える（名前・リンク）。次からは、検索欄をタップすると「前に使ったお店」として出て、1タップで載せられる
   - 二次会の候補の欄には、一次会の「前に使ったお店」「いつものお店」は出ない。二次会は二次会だけの履歴（前に候補に出たお店）が出る
   - サークルでよく行くお店は、`index.html` の `REGULAR_SHOPS` に書いておくと、全員の端末で「いつものお店」として候補に出る（ひらがなで打っても当たる）
   - ロタまでの所要時間や到着予定の時刻は出さない（歩く班と電車の班で変わり、目安にならないため、やめた）
   - ③で追加したお店は、名前の横のリンクアイコンからGoogleマップのページを開ける
   - 誰もいないお店は「×」で候補から消せる
   - お店を選ぶと、検索欄とほかのお店の候補は畳まれ、選んだお店だけが残る。空いた所に「このお店に連れてきた人を追加」の枠が出る。移動中・到着後に別のお店へ変えたいときは、「別のお店に変更」を押すと候補が開く
   - 「このお店に連れてきた人を追加」では、チェックした人は、その場で同じお店に入る（アプリを使っていない人もOK）。チェックを外すと、その人は「まだ選んでいない」に戻る
4. 食べ終わったら「ロタへ向かう」→ ロタに着いたら「ロタに着いた」を押す
   - 「いっしょに行く人」にチェックが入っていれば、同じ操作がその人たちにも反映される（ロタで幹事が一括で「到着」にもできる）
   - お店はいつでも選び直せる（移動中・到着後でも、いまの状況はそのままお店だけ変わる）。「いっしょの人」にチェックした人も一緒に移る
   - 画面の下に「一次会／二次会／みんなの状況」の3つのタブがあり、切り替えるだけでスクロールせずに見られる（二次会には候補の数、みんなの状況にはロタ到着の人数がタブに出る）。一次会のタブは、お店を選ぶカードの下、画面の下端（タブの上）に「自分のカード」が固定されていて、お店の欄が伸び縮みしても動かない
   - 「自分のカード」に、いまの状況と3つの大きなボタン（お店にいる／ロタへ向かう／ロタに着いた）が並ぶ（サークル出欠と同じ作り）。押すと上から短いメッセージ（トースト）が出る
   - 「戻す」ボタンはない。選んでいるお店をもう一度押すと「まだ選んでいない」に戻せる。名前をまちがえたときは、自分のカードの名前をタップして選び直す
5. 二次会：ロタで「二次会の候補」にお店を追加する（だれでも出せる。出した人は自動でハートが付く）。行きたいお店のハートを押すと、ハートの下に押した人数が出る。ハートを長押しする（または人数の数字を押す）と、押した人の一覧が画面の下から上がってくる（外側を押すか、見出しを下へ引くと閉じる）。候補は、人数の多い順に並べ替わる。もう一度押すと取り消し。だれも行きたくない候補は「×」で消せる
6. 状況は「お店にいる / ロタへ移動中 / ロタ到着」の3つ。全員がロタ到着になると見出しに「全員そろいました」と出る。通信が3秒以上切れると、ヘッダーに「オフライン」と出る。お店を選んでいない出席者は「⏳ まだ選んでいない」に出る。人数（ロタ到着 3 / 12人）は名簿＋名簿外の参加者
   - ボードの内容は自動で更新されるので、読み込み直す必要はない。読み込み直しても（下へ引っ張って更新など）、「ボードを開いています…」の画面を挟まず、見ていたタブのままボードに戻る
7. ボードは翌朝4時に自動で終了し、データも消える（終了ボタンはない）
- 出席者が途中で変わったら「出席者名簿を更新」で取り込み直せる（開いたとき、名簿が30分以上古ければ自動でも取り込む）
- 今日の出席者が0人のとき（〇が1つも無く、今日の練習の記録も無いとき）は、ボードは始まらない。「記録」をせずに出欠リセットだけした日は、名簿を作れない（リセット前に誰かが開いていれば、名簿は残る）

## Firebase の設定（全員で共有するために必要・無料）
`index.html` 冒頭の `FIREBASE_CONFIG` が空だと、同じブラウザの別タブ間だけで動く「お試しモード」になります。
1. https://console.firebase.google.com でプロジェクトを作成（Spark プラン＝無料）
2. Authentication →「ログイン方法」→ **匿名** を有効化
3. Realtime Database を作成 → 「ルール」に `database.rules.json` の中身を貼って公開
4. プロジェクトの設定 → マイアプリ（Web）→ 表示される `firebaseConfig` を `index.html` の `FIREBASE_CONFIG` に貼る
5. Authentication → 設定 → 承認済みドメインに `take-daigakusei.github.io` を追加

## 出欠アプリとの連携（最初に1回だけ）
出席者の名前は、出欠アプリ（`../サークル出欠`）のサーバーが、ボード（Firebase）へ直接書き込みます。集合ボードは「今日の名簿を入れて」と合図を送るだけで、返ってくるのは結果だけです。**連携キーはありません**（リンクにも端末にも、漏れて困る値を置かない）。
1. 先に上の「Firebase の設定」を済ませる
2. 出欠アプリの `app.js` の `BOARD_FIREBASE` に、Firebase の `databaseURL` と `apiKey` を書く（`index.html` の `FIREBASE_CONFIG` と同じ値）
3. `clasp push` のあと、Apps Script エディタで `setupBoardSync` を実行（オーナーのみ）。外部通信の許可を求められたら許可する。実行ログに `boardSync: {"ok":true,…}` が出れば成功（出席者が0人の日は `noAttendees` と出る）
4. 出欠アプリを**新しいバージョンとして再デプロイ**する（「デプロイを管理」→ 編集 → 新バージョン）
5. 集合ボードの右上の設定ボタン →「出欠アプリの設定」に、出欠アプリのウェブアプリのURL（`…/exec`）を入れて保存
6. 同じ画面の「メンバーに配るリンクをコピー」を押し、グループLINEなどで配る。メンバーはそのリンクを**一度だけ**開けば設定が保存され、以後は普通に開くだけでよい
- 配るリンクに入るのは、出欠アプリのURLだけ
- 合図は誰でも送れるが、起きるのは「サーバーが正しい名簿を書き直す」ことだけ（1分に1回まで）。名簿は足すだけで、消さない
- 設定が入っていない端末でも、すでに始まっているボードには入れる（ボードを始められるのは、出欠アプリのURLが入っている端末だけ）
- お試しモード（Firebase 未設定）では、出欠アプリとはつながらない。代わりに見本のボード（名簿4人・お店3件）が自動で作られる
- 公開後、出欠アプリに「飲み会ボードを開く」ボタンを足す予定。ボタンは `…/WCMs/#n=名前` で開き、その名前が端末に登録される（未登録ならそのまま登録、別の名前で登録済みなら確認が出る）。名前入りのリンクは、ほかの人に送らない

## ルール
- 名簿など個人情報を含むファイルはコミットしない（`.gitignore` 済み）
- ログインやメンバー間のデータ共有が必要になったら、Firebase の無料枠（Spark プラン）を使う
